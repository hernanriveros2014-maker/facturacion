  Misma VPS que ArriendaVIP, SIN impacto en turismo ni sinfon-ia.cl
================================================================================

DOMINIO: qa.facturacion.sinfon-ia.cl
  ✓ No interfiere con arriendavip.cl
  ✓ No interfiere con sinfon-ia.cl / www.sinfon-ia.cl (turismo white-label)
  ✓ Facturación en puerto 8001, BD facturacion1

================================================================================
CLOUDFLARE — zona sinfon-ia.cl → DNS → Registros
================================================================================

Crear UN registro (no borrar los de sinfon-ia.cl / www):

  Tipo:     A
  Nombre:   qa.facturacion
  Contenido: IP de la VPS (la misma que arriendavip.cl)
  Proxy:    Proxied (naranja) — recomendado
  TTL:      Auto

Resultado: qa.facturacion.sinfon-ia.cl → VPS

SSL/TLS (zona sinfon-ia.cl): Full o Full (strict)

No crear CNAME a qa.arriendavip.cl.

================================================================================
VPS — primera vez (ya instalado sidecar) o reconfigurar dominio
================================================================================

cd /var/www/facturacion
git pull origin main

sudo DOMAIN=qa.facturacion.sinfon-ia.cl \
     SSL_EMAIL=admin@sinfon-ia.cl \
     bash deploy/reconfigure-domain.sh

Instalación nueva desde cero:

sudo DOMAIN=qa.facturacion.sinfon-ia.cl \
     ENABLE_SSL=1 \
     SSL_EMAIL=admin@sinfon-ia.cl \
     bash deploy/install-sidecar-vps.sh
